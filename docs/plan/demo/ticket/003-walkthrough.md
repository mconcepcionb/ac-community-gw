# Scripted walkthrough

## Goal

`docs/demo.md`: a five-minute script for prospective server owners.

## Requirements

- Preflight (Discord app/guild/demo role, DSNs), start, the numbered script
  (sign in, player purchase and delivery, staff console, the hidden SOAP layer),
  reset, troubleshooting.
- Each step states what to click and what the audience should notice.

## Acceptance criteria

- A presenter can run the demo from the document without other notes.
