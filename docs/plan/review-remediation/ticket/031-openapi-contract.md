# 031 — OpenAPI contract fixes

**Phase:** 5 · **Gate:** G-standard, contributes to G5-infra · **Depends on:** 001

## Goal

Make the generated spec accurately type request bodies and declare the session
security scheme, so the TypeScript client is sound.

## Findings addressed

- Medium: every JSON body is emitted as `oneOf: [{type: object}, {$ref: ...}]`,
  generating `body: { [key: string]: unknown } | CreateAccountRequest` and a
  permissive Zod schema.
- Medium: no `securitySchemes`/`security` is declared despite cookie-session auth
  and documented `401`/`403` responses.
- Nit: `details: {}` (untyped `any`), empty `externalDocs`, `uniqueItems: false`
  noise, and a path body not marked `required` while others are.

## Context

`api/swagger.yaml` (generated by `swag v2` from Go annotations),
`docs/plan/spa/README.md` openapi conventions, `web/openapi-ts.config.ts`.
Generated files are not hand-edited; the fix is in the annotations/config.

## Atomic change

Fix the swag annotations so each body is a single `$ref`, add a security scheme,
and clean the spec noise. Regenerate the spec and the TS client.

## Requirements

- Make request bodies resolve to a single `$ref` schema (investigate the swag v3.1
  annotation that causes the union; adjust the `@Param body <Type> true` form or
  the type's `@name`).
- Add a `securitySchemes` entry for the session cookie (`apiKey` in `cookie`,
  name `acgw_session`) and reference it globally (with per-operation opt-out for
  public endpoints: login, callback, health, readiness).
- Give `details` a concrete type (or remove it from response DTOs).
- Remove empty `externalDocs`; align `required` on request bodies.
- Regenerate `api/swagger.yaml` and `web/src/api/generated/**`; commit both.
- `task openapi:check` and `task openapi:client:check` (or equivalent) must be
  clean.

## Tests

- `task openapi:check` green.
- Test: a generated request body type for a known endpoint is the named DTO, not a
  union with `{ [key: string]: unknown }`.
- Test: the spec contains a security scheme and public operations are exempt.
- Frontend typecheck stays green after regeneration.

## Acceptance criteria (gate G-standard, G5-infra)

- `task check` green.
- Generated TS request bodies are precise for all mutating endpoints.
- The spec declares the session security scheme.

## Rollback

Revert the spec/client and the annotation changes.

## Out of scope

- Changing the wire format or endpoint behaviour.
- Adding new endpoints.
